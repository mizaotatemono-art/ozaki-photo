# ozaki-photo
## 体操採点ビューア（`gymnastics/`）

スマホで横から撮った器械体操の動画を読み込み、ブラウザ上で姿勢（骨格）を解析して、
再生しながら技の難度・姿勢の減点・得点（D / E / 決定点）を表示するページです。

- 開き方：`gymnastics/index.html`（GitHub Pages なら `…/gymnastics/`）。サーバー不要・動画は端末の外に送信しません。
- 使い方：種目を選ぶ → 撮影 or 動画を選ぶ → 「姿勢を解析する」→ 候補を登録して難度（A〜J）と形を選ぶ → 再生。
- 採点：FIG 2025–2028 年版採点規則（日本体操協会訳）に沿った目安。数える技 8（ジュニアは 6＋終末技）、
  グループ要求 各0.5、終末技グループ上限0.5、着地の加点0.1、実施減点 小0.1 / 中0.3 / 大0.5 / 落下1.0。
- 骨格解析：MediaPipe Pose Landmarker（初回はモデルを読み込むためネット接続が必要）。
